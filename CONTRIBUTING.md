# Contributing

1. Never commit real patient data, credentials, tokens, private keys, model caches, or generated indexes.
2. Add tests for authorization and tenant isolation with every data-access change.
3. Keep PHI out of logs, exception messages, fixtures, and screenshots.
4. Document trust-boundary changes in `docs/ARCHITECTURE.md`.
5. Run formatters, tests, dependency scans, and secret scans before opening a pull request.

All sample records must be synthetic and clearly labeled.
